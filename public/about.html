About关于

A small index of public data sources for FOMC research, plus a daily snapshot of seven series drawn from those sources.一个 FOMC 研究用的公开数据源索引，另附七个序列的每日快照。

What it is定位

The index lists statistical databases, official releases and literature. The snapshot tracks policy rates, inflation, employment, equities, gold, crude and volatility, refreshed once a day.索引列出统计数据库、官方发布与文献。快照跟踪政策利率、通胀、就业、股指、黄金、原油与波动率，每日刷新一次。

How it is built实现

Static HTML, CSS and plain JavaScript, served by a Cloudflare Worker. A Python script runs in GitHub Actions each day, pulls a 400-day window per series, merges it into the stored history, and commits the data file. The same job deploys the site.静态 HTML、CSS 与原生 JavaScript，由 Cloudflare Worker 托管。Python 脚本每天在 GitHub Actions 中运行，抓取每个序列最近 400 天，合并进已有历史，提交数据文件，同一任务完成部署。
